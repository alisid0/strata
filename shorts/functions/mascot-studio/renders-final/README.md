# QUBIX cube animation pack

Ten compositing-ready mascot clips rendered from one canonical Three.js model.

## Format

- VP9 WebM with alpha
- 270 × 480, vertical 9:16
- Constant 30 fps
- No audio
- One complete animation cycle per file

Scale the clips by exactly 4× with nearest-neighbour filtering for a 1080 × 1920 Short.

## Clips

| File | Duration | Intended use |
| --- | ---: | --- |
| `qubix-cube-idle.webm` | 3.4 s | Resting and blinking |
| `qubix-cube-curious.webm` | 3.2 s | Inspecting a concept |
| `qubix-cube-think.webm` | 4.0 s | Working through an idea |
| `qubix-cube-surprise.webm` | 2.6 s | Unexpected result |
| `qubix-cube-celebrate.webm` | 3.0 s | Correct answer |
| `qubix-cube-error.webm` | 2.5 s | Incorrect or inconsistent result |
| `qubix-cube-point-left.webm` | 3.0 s | Direct attention left |
| `qubix-cube-point-right.webm` | 3.0 s | Direct attention right |
| `qubix-cube-press.webm` | 3.2 s | Interact with a button |
| `qubix-cube-transition.webm` | 3.0 s | Move between lesson beats |

The transparent clips can be layered directly over the Functions laboratory, pixel-art scenes, captions, and interface recordings.
